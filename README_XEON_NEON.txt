XEON NEON — SKY BLUE / ELECTRIC NEON EDITION
==========================================

ISI:
- XEON_NEON_Library.lua : GUI utama (tampilan biru, judul XEON NEON).
- XEON_NEON_Core.lua : versi inti GUI.
- XEON_NEON_Core2.lua : GUI yang mendukung parameter Namespace/Title.
- XEON_NEON_Discord.lua : layar Discord; warna, judul, dan logo XN diganti.
- XEON_NEON_Loader.lua : pemilih game yang memuat script dari URL luar.
- XEON_NEON_Start.lua : pilihan menjalankan loader lokal bila lingkungan mendukung readfile.
- File obfuscated & game lain : disertakan apa adanya agar tidak merusak isi terenkripsi.
- LEGACY_SPEEDBOOST_REFERENCE.txt : baris loader lama sebagai referensi saja.

WARNA TEMA:
- Deep navy: #071329
- Sky blue:  #35CAFF
- Electric:  #1173F5
- Ice blue:  #AF F2 FF (hex without spaces: #AFF2FF)

PENTING:
1. Perubahan UI ada pada file Lua terbuka. File dengan proteksi/obfuscation
   tidak bisa dipastikan ikut rebranding karena source-nya tidak tersedia.
2. Loader game masih mengambil script dari URL pihak ketiga yang lama. Saat
   dipakai, game tertentu bisa tetap menampilkan versi lama; untuk rebrand
   menyeluruh diperlukan source dari URL yang bersangkutan dan host yang Anda
   miliki atau kendalikan. Jangan hanya ganti URL ke nama yang belum di-host.
3. Link Discord tetap alamat aslinya. Ubah INVITE_URL/INVITE_TEXT di file
   XEON_NEON_Discord.lua bila Anda mempunyai server Discord sendiri.
4. Perubahan diverifikasi secara statis; belum diuji menjalankan game Roblox.

Desain: XEON NEON — sky-blue, cyan gradient, navy base, XN emblem.
